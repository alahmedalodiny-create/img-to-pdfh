# PDF Scanner Plus

A lightweight Flutter app for converting images to PDF with Unity Ads.

## Features
- Convert images to PDF
- Reorder images before conversion
- Scanner (camera capture to PDF)
- View, share, delete PDF files
- Unity Ads integration

## Build
This project includes GitHub Actions workflow for automatic APK builds.

## Unity Ads Setup
Replace test IDs in `lib/config/ads_config.dart` with your production IDs before release.
